## 条目 001 · 长任务子 agent 运行中中断，未产出最终报告

- **现象**：文档填充/验收子 agent 在长时间运行中多次「failed before it finished」，关闭消息为空或处于中途自检/读取阶段，最终报告未产出。
- **根因**：子 agent 长轮次运行不稳定（可能受运行时/上下文限制影响）；失败发生在收尾汇报前，而非任务执行中。
- **修复**：以磁盘产物为准验收（文件已落盘且内容完整即视为交付）；主 agent 保留设计稿关键事实与自查证据兜底。
- **预防**：
  1. 分派任务时写死「读路径 + 验收标准 + 产物文件清单」，确保即使子 agent 中断，产物仍可独立核验；
  2. 长任务拆小批次，避免单次子 agent 轮次过长；
  3. 主 agent 对关键事实（数值/规则/契约）保留独立核查能力，不依赖子 agent 报告。
- **规范反哺**：B-06 子 agent 创建规范 + B-07 引导（验收与实现分离、以产物为准）。
- **是否 AI 犯错**：是（子 agent 中断；主 agent 已兜底）。
- **出现次数**：2（编写 1 次、验收 3 次中断）

## 条目 002 · 峰谷时间轴光标写死（不随北京时间变化）

- **现象**：GUI 中时间轴光标停在固定位置（peak 43.75% / idle 90%），不随当前北京时间移动。
- **根因**：`primitives.tsx` Timeline 用常量 `TIMELINE_CURSOR[period]`（设计稿演示值）渲染 `.tl-cur` 的 left；Metro 列车同理用 `TRAIN_CURSOR`。契约 §3 原写「高峰 43.75%/空闲 90%」被误当成品实值。
- **修复**：新增 `cursorPercentAt()`（`北京分钟数/1440×100`），时段 store 快照携带 `cursorPercent` 并按时钟刷新（≤5s tick），Timeline/Metro 改传动态值。
- **预防**：设计稿静态演示值与运行时动态行为分离；契约明确「接入后按实时时钟计算，不得写死」。
- **规范反哺**：001-接口契约 §3、001-测试用例 用例 6 已改为动态契约。
- **是否 AI 犯错**：是（实现把演示常量当成品实值）。
- **出现次数**：1

## 条目 003 · 06 终端风格展开态宽度不一致（横向溢出）

- **现象**：06 终端风格组件比其它风格宽，侧边栏布局不一致。
- **根因**：`.ds-style-06 .tline { white-space: nowrap }` + 终端 flex 行（等宽数字列）无收缩约束，内容固有宽度超过侧边栏列宽，组件被撑宽；其它风格用 `table-layout: fixed; width: 100%` 自适应。
- **修复**：`.ds-pv`/`.w` 加 `width: 100%; min-width: 0`；终端 `.tline` 允许换行、`.tt-row .m` 超长省略（`overflow:hidden; text-overflow:ellipsis`）、数字列 `flex:none`。
- **预防**：新增 002-测试用例 宽度一致性回归用例（各款展开态宽度一致、无横向溢出）。
- **规范反哺**：B-01 开发规范（作用域样式需约束宽度与溢出）。
- **是否 AI 犯错**：是。
- **出现次数**：1
