> 状态: 草稿 | 最近更新: 2025-08-21

## 0. 接口形态说明

本项目为纯前端 DSH client widget，无后端 HTTP 接口（003-后端-数据服务 不填）。
本契约以「bundle 配置 / 插件入口 / 挂载位置 / 生命周期」形式定义与 DSH Web 的集成点。

## 2. Bundle / 平台契约（DSH 插件分发）

```jsonc
// package.json（示意，随正式版字段调整）
{
  "name": "dsh-deepseek-peak-valley",
  "type": "module",
  "main": "lib/index.js",
  "exports": {
    ".": { "types": "./lib/types/index.d.ts", "default": "./lib/index.js" },
    "./client": { "types": "./lib/types/client/index.d.ts", "default": "./lib/client.js" },
    "./cordis.patch.yml": "./cordis.patch.yml",
    "./package.json": "./package.json"
  },
  "dsh": {
    "bundle": { "patch": "./cordis.patch.yml" },
    "client": {
      "platform": "web",
      "inject": ["@deepseek-ai/dsh-client-runtime"]
    }
  }
}
```

- 平台 = `web`（DSH Web 内嵌，dsh client 插件）；必须同时有 `dsh.client.platform: "web"` 与真实存在的 `exports["./client"]`；
- `cordis.patch.yml` 为顶层数组，声明稳定行身份（`id` / `name` / `config`）；
- client bundle 构建产物按 Harness 约定包装为 `window.__ModuleLoader__.load({ id, factory })`。

## 3. Client 插件入口契约

```ts
import type { ClientContext } from '@deepseek-ai/dsh-client-runtime/client'
import type { PeriodState, DualState, PriceTable } from '001-核心引擎/001-接口契约'

export const inject = ['slots']            // 依赖注入：等待 slots 等必需 service
export function apply(ctx: ClientContext): void {
  // 挂载组件到左侧边栏（左下角 · 设置上方）；注册/卸载随 ctx fiber dispose
}
```

- 注册的 controller / listener / 样式 / DOM 必须随 client fiber dispose 清理；
- per-session 状态按 `SessionId` 分桶（如双态展开/收起按会话记忆时）；
- 接入后按当前北京时间自动判定 `PeriodState`（演示页默认高峰、可手动切换）。

## 4. 挂载位置契约

| 项 | 规格 |
|----|------|
| 位置 | 左侧边栏 · 左下角 · 设置上方 |
| 展开态 | 侧边栏宽度下的完整报价（002 各款风格） |
| 收起态 | 侧边栏收起时折叠为紧凑指示器（图标栏），位置不变 |
| 设置入口 | 组件下方齿轮「设置」（示意实际位置） |

## 5. 生命周期 / HMR 语义

- **client bundle 内容变化** → 可 client HMR（需 `tsdown --watch` 等构建 watcher 持续重写 `lib/client.js`）；
- **manifest / exports / profile bundles / 插件集合 / host 代码变化** → 需要重启，不能热更；
- 普通构建后无 watcher 时：刷新现有 DSH Web 页面验证，不启动替代 Vite server。

## 6. 免责与数据边界

- 免责声明随组件常驻：价格基于 IT之家公开的 DeepSeek V4 分时段报价，仅作演示；正式接入以官方实时接口为准；
- 价格表为**静态内置数据**（001 权威），正式接入时替换为官方实时接口数据，契约不变。
