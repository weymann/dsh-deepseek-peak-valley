# 003-DSH 集成层 · 前端-页面交互（Web）

> 状态: 草稿 | 读者: Web 前端（其余不读）
> 页面 / 组件 / 交互与状态，对齐接口契约（003-接口契约；业务结构与双态见 001-前端-页面交互、002-前端-页面交互）

## 1. 挂载形态（DSH Web GUI 内）

组件作为 DSH client 插件挂载到 **DSH Web 左侧边栏 · 左下角 · 设置上方**：

- **展开 · 侧边栏**：以完整报价形态显示（头部 / 时间轴 / 价格表 / 页脚），随侧边栏宽度自适应；
- **收起 · 图标栏**：侧边栏收起时折叠为紧凑指示器（发光圆点 / 迷你线路 / 光标 / 太阳月亮等，按 002 所选风格），位置保持在左下角、设置图标上方；
- 设置入口：组件下方齿轮「设置」，与 DSH 设置入口并置示意实际位置。

## 2. 时段状态（接入后）

- 组件按**当前北京时间自动判定** `body[data-period]`（peak / idle），十款风格同步响应；
- 演示期提供手动切换（`data-set-period` 按钮，`aria-pressed` 同步）；接入后手动切换仅作演示覆盖，刷新回到自动判定；
- 跨会话展开/收起状态（`DualState`）按会话记忆时以 `SessionId` 分桶。

## 3. 生命周期与 HMR 交互

- **client bundle 内容变更**：构建 watcher（`tsdown --watch`）持续重写 `lib/client.js`，DSH Web 通过 HMR 触发 fiber dispose / reload；
- **manifest / exports / profile / host 代码变更**：需重启目标 profile；
- 普通构建后（无 watcher）：刷新现有 DSH Web 页面即可看到最新组件；
- dispose 时清理 DOM、事件监听、样式注入与 controller，不留残留。

## 4. 可访问性

- 组件内交互沿用 001 契约：`aria-pressed`（时段切换）、`aria-expanded`（价格表）、`:focus-visible` 轮廓、图标 `aria-hidden`、`prefers-reduced-motion` 关闭动画；
- 组件为嵌入式 widget，不劫持侧边栏整体焦点顺序。
