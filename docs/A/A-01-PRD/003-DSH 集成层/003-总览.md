## 模块职责

DSH 集成层把「DeepSeek 分时段计费组件」以 **DSH client 插件（platform=web）** 形式交付并挂载进 **DSH Web GUI**：

- 以 **dsh client bundle**（React + TypeScript 构建）分发给 DSH Web 内嵌使用；
- 定义 bundle / 平台 / 插件入口 / 挂载位置等集成契约；
- 把组件挂载到 **左侧边栏 · 左下角 · 设置上方**，收起侧边栏时折叠为紧凑指示器；
- 说明 HMR / 重启语义（client bundle 内容热更，manifest 等变更需重启）；
- 消费 001-核心引擎 的时段判定与价格数据（自动按北京时间判定时段）。

集成层**不定义**业务数据与规则（时段/价格/双态状态引用 001-接口契约），也**不定义**风格视觉（引用 002-接口契约）。

## 功能清单

- [x] 以 DSH client 插件形态交付（platform=web，client bundle）
- [x] bundle 分发包契约（`package.json.dsh.bundle.patch` → `cordis.patch.yml`）
- [x] client 入口契约（`inject` / `apply(ctx: ClientContext)`）
- [x] 挂载位置：左侧边栏 · 左下角 · 设置上方
- [x] 收起侧边栏 → 折叠为紧凑指示器
- [x] 接入后按当前北京时间自动判定时段（演示页默认高峰、可手动切换）
- [x] HMR 语义：client bundle 内容变更热更（需构建 watcher）；manifest/exports/profile 变更需重启
- [x] 资源清理：DOM / 事件监听 / 样式随 client fiber dispose
- [x] 免责声明随组件常驻：价格仅作演示，正式接入以官方实时接口为准
