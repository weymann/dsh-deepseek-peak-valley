# 001-核心引擎 · 总览

> 状态: 草稿 | 最近更新: 2025-08-21
> 来源: 设计稿 deepseek-pricing-widget-styles.html 抽取

## 模块职责

核心引擎承载「DeepSeek 分时段计费组件」的**数据、规则与状态**，是所有风格与 DSH 集成的公共底座：

- **时段规则（北京时间）**：判定当前处于高峰 / 空闲；
- **价格口径与价格表**：模型 × 计费项 × [空闲, 高峰] 的稳定单价数据；
- **双态状态**：展开（侧边栏）↔ 收起（图标栏）的状态机；
- **时间轴契约**：24h 分段宽度与当前时段光标位置；
- **全局状态约定**：`body[data-period]`、时段切换按钮、价格表展开收起等 DOM 契约；
- **统一语义配色**：高峰 = 暖色（橙 / 琥珀 / 红），空闲 = 冷色（蓝 / 青 / 绿），全系列一致。

核心引擎**不负责**某一种风格的具体视觉（由 002-十款风格组件库 承担）与 DSH 挂载方式（由 003-DSH 集成层 承担），三者以 001-接口契约 的共享类型对齐。

## 功能清单

- [x] 时段规则（北京时间）：高峰 = 09:00–12:00、14:00–18:00；空闲 = 其余全部时段
- [x] 价格口径：单位 元 / 百万 tokens；高峰 = 空闲 × 2
- [x] 价格表：V4-Flash / V4-Pro × 计费项 × [空闲, 高峰]（12 个单价）
- [x] 双态状态：展开 · 侧边栏 / 收起 · 图标栏
- [x] 时段判定：接入后按当前北京时间自动判定；演示默认高峰、可手动切换
- [x] 时间轴分段：空闲 37.5% / 高峰 12.5% / 空闲 8.34% / 高峰 16.66% / 空闲 25%；当前光标 高峰 43.75% / 空闲 90%
- [x] 语义配色：高峰 = 暖色（橙 / 琥珀 / 红），空闲 = 冷色（蓝 / 青 / 绿），全系列统一
- [x] 免责声明：价格基于公开报价仅作演示，正式接入以官方实时接口为准
