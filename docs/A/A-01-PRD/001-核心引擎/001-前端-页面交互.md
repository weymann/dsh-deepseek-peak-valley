# 001-核心引擎 · 前端-页面交互（Web）

> 状态: 草稿 | 读者: Web 前端（其余不读）
> 页面 / 组件 / 交互与状态，对齐接口契约（001-接口契约 为权威类型来源）

## 1. 组件位置

- 挂载于 **左侧边栏 · 左下角 · 设置上方**。
- **收起侧边栏时折叠为紧凑指示器**（图标栏）。

## 2. 双态结构

### 展开 · 侧边栏（`.w`，完整报价）
自上而下：

1. **头部 `.w-head`**：组件名（`DeepSeek 计费`）+ 时段徽章（圆点 + `.lpk` 高峰 / `.lidle` 空闲）。
2. **时间轴 `.w-tl`**：
   - 轨道 `.tl-track`：5 段（空闲 37.5% → 高峰 12.5% → 空闲 8.34% → 高峰 16.66% → 空闲 25%）；
   - 当前光标 `.tl-cur`：**按当前北京时间动态定位**（当日分钟数/1440×100%，随时间移动，0.3s 位移动画）；
   - 元信息 `.tl-meta`：`高峰 09:00–12:00 · 14:00–18:00｜其余空闲`。
3. **价格表切换 `.w-toggle`**（按钮，**默认收起**）：文字「价格表」+ 展开指示 chevron；点击在收起/展开间切换。
4. **价格表 `.wt`**：表头 `计费项 / 空闲 / 高峰`；两模型分组行（V4-Flash / V4-Pro），每组 3 行计费项；当前时段列以高亮条 `.hx`（`.hp` 高峰 / `.hi` 空闲）标记。
5. **页脚 `.w-foot`**：`元 / 百万 tokens · 北京时间`。

### 收起 · 图标栏（紧凑指示器）
- 折叠为紧凑指示器（如发光圆点 / 迷你线路 / 终端光标等，逐款见 002），配 `.lpk` 峰 / `.lidle` 闲 文字；
- 位置仍位于侧边栏左下角、设置图标上方（下方为 `.sb-set`/`.rail-set` 齿轮「设置」入口）。

## 3. 时段切换

- 顶部「模拟时段」分段控件 `role="group"` `aria-label="模拟时段"`：两个按钮 `data-set-period="peak"` / `data-set-period="idle"`；
- 按钮 `aria-pressed` 与 `body[data-period]` 同步；当前时段按钮高亮，未选中时段文字 `.lidle`/`.lpk` 隐藏；
- **接入后**：默认按当前北京时间自动判定时段（演示页默认停留在高峰、支持手动切换）。

## 4. 设置入口

- 组件下方为齿轮图标 +「设置」按钮（`.sb-set` / `.rail-set`）；展开态与收起态均可见，示意实际位置。

## 5. 交互细节

- **价格表展开/收起**：点击 `.w-toggle` 切换容器 `.w` 的 `.is-collapsed`，同步 `aria-expanded`；收起后隐藏价格表与页脚，保留头部与时间轴；chevron 随状态旋转。
- **时段切换**：全局同步，所有风格、展开态与收起态同时响应，无独立状态。
- **动画**：光标位移动画 0.3s；脉冲风格圆点 2.4s 循环脉冲。

## 6. 可访问性

- 按钮语义：时段切换用 `aria-pressed`，价格表切换用 `aria-expanded`；
- `:focus-visible` 提供 2px 强调色轮廓；
- 时段控件声明 `role="group"` + `aria-label`；
- `prefers-reduced-motion: reduce` 时关闭全部动画与过渡；
- 图标均 `aria-hidden="true"`，文字信息不依赖颜色/图标单独传达。
