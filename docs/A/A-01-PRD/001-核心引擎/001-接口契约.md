# 001-核心引擎 · 接口契约（唯一多角色共读）

> 状态: 草稿 | 最近更新: 2025-08-21
> 定位: 前端定「要什么」/ 后端定「给什么」/ 测试定「验证什么」
> 权威声明: 本文件是共享数据模型（时段规则 / 价格口径 / 价格表 / 双态状态）的**唯一权威定义**；
> 002-十款风格组件库 与 003-DSH 集成层 的接口契约一律**引用本文件类型，不重复定义、不冲突**。

## 0. 接口形态说明

本项目为**纯前端 DSH client widget**（React + TypeScript，构建为 dsh client bundle，platform=web），
**无后端 HTTP 接口**（001-后端-数据服务 不填）。因此本契约不定义 HTTP 方法/路径，而是以
「类型 / 数据结构 / 事件 / 配置」形式定义稳定契约。

## 1. 共享数据模型（权威）

```ts
/** 时段状态：peak = 高峰 / idle = 空闲（北京时间判定） */
export type PeriodState = 'peak' | 'idle'

/** 双态状态：expanded = 展开 · 侧边栏 / collapsed = 收起 · 图标栏 */
export type DualState = 'expanded' | 'collapsed'

/** 模型名 */
export type ModelName = 'V4-Flash' | 'V4-Pro'

/** 计费项 */
export type BillingItem = '输入·缓存命中' | '输入·缓存未命中' | '输出'

/** 价格单位：元 / 百万 tokens */
export type PriceUnit = '元/百万tokens'

/** 时段规则（北京时间）：高峰 = 09:00–12:00、14:00–18:00；空闲 = 其余全部时段 */
export interface PeriodRule {
  timezone: 'Asia/Shanghai'
  peakWindows: [{ start: '09:00', end: '12:00' }, { start: '14:00', end: '18:00' }]
  // idle = 一日内除去 peakWindows 的全部时段
}

/** 价格口径：高峰 = 空闲 × 2 */
export interface Pricing {
  unit: PriceUnit
  peakMultiplier: 2
}

/** 价格表：模型 × 计费项 × [空闲, 高峰] */
export type PriceTable = Record<ModelName, Record<BillingItem, [idle: number, peak: number]>>
```

## 3. 时间轴契约（24h 分段）

展开态时间轴按北京时间划分为 5 段（从左到右）：

| 时段 | 时间范围 | 宽度 | 属性 |
|------|----------|------|------|
| 空闲 | 00:00–09:00 | 37.5% | `.s-idle` |
| 高峰 | 09:00–12:00 | 12.5% | `.s-peak` |
| 空闲 | 12:00–14:00 | 8.34% | `.s-idle` |
| 高峰 | 14:00–18:00 | 16.66% | `.s-peak` |
| 空闲 | 18:00–24:00 | 25% | `.s-idle` |

当前时段光标 `.tl-cur`：**动态定位**——`left = 当前北京时间当日分钟数 / 1440 × 100%`（随时间自动移动，0.3s 位移动画）。
示例：北京时间 10:30 → `left: 43.75%`；08:58 → `left: ≈37.4%`。
（演示页的 43.75% / 90% 仅为静态示意；接入后必须按实时时钟计算，不得写死。）

## 4. 事件与 DOM 契约

| 契约点 | 规格 | 说明 |
|--------|------|------|
| 全局时段状态 | `body[data-period="peak"\|"idle"]` | 单一事实源，所有风格读取 |
| 时段切换按钮 | `data-set-period="peak"\|"idle"` + `aria-pressed="true\|false"` | 点击切换并同步 body 状态 |
| 价格表展开/收起 | `.w-toggle`（按钮）+ `aria-expanded` + 容器 `.w` 的 `.is-collapsed` | **默认收起**（`aria-expanded="false"`、价格表与页脚隐藏）；点击展开显示价格表与页脚，再点收起 |
| 双态文字 | `.lpk`（高峰）/ `.lidle`（空闲） | 由 body 时段控制显示，永不共存 |
| 语义配色 | 高峰 = 暖色（橙 / 琥珀 / 红）；空闲 = 冷色（蓝 / 青 / 绿） | 全系列统一（002 逐款落地） |
| 单位标注 | `元 / 百万 tokens · 北京时间` | 页脚 `.w-foot` / `.term-foot` |
