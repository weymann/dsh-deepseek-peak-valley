# 002-十款风格组件库 · 总览

> 状态: 草稿 | 最近更新: 2025-08-21
> 来源: 设计稿 deepseek-pricing-widget-styles.html 抽取

## 模块职责

十款风格组件库提供「DeepSeek 分时段计费组件」的 **10 种可选视觉风格**（编号 / 中文名 / 英文名 / 风格标签 / 描述），
每款都支持**双态**（展开 · 侧边栏 / 收起 · 图标栏），并遵循**统一语义配色**（高峰 = 暖色，空闲 = 冷色）。

组件库**不定义**数据与规则：时段规则、价格口径、价格表、双态状态一律引用 001-核心引擎 的权威类型（001-接口契约）；
所有风格消费同一份 `body[data-period]` 全局状态，切换时段时十款同步响应。

## 功能清单

- [x] 01 脉冲 Pulse（深色 · 发光 · 科技）：发光圆点脉冲提示当前时段，适合常驻侧边栏暗色主题
- [x] 02 留白 Minimal（浅色 · 极简 · 细线）：彩色圆点 + 细时间轴，数字即信息，几乎零装饰
- [x] 03 票据 Receipt（浅色 · 纸质 · 盖章）：等宽对账排版，当前时段斜盖印戳，附锯齿撕线与条形码
- [x] 04 时刻线 Metro（浅色 · 地铁 · 24h）：一整天画成地铁线路，站点点出 09/12/14/18，当前位置是一列「列车」
- [x] 05 胶囊 Pills（浅色 · 圆润 · 亲和）：大圆角 + 马卡龙色块，价格是彩色小胶囊，时段是圆点徽章
- [x] 06 终端 Terminal（深色 · CLI · 日志）：`$ ds rate --now` 查询、日志式颜色状态行、等宽价格对齐
- [x] 07 粗野 Brutalist（浅色 · 硬边 · 高对比）：2px 黑边 + 硬投影 + 反色块，当前价格列整列反白
- [x] 08 玻璃 Glass（深色 · 毛玻璃 · 通透）：半透明毛玻璃浮层悬浮渐变底色上，时段色以光晕呈现
- [x] 09 昼夜 DayNight（明暗 · 太阳月亮 · 直观）：整卡随时间变色，高峰白昼 / 空闲夜空，太阳月亮图标直述时段
- [x] 10 编辑 Editorial（浅色 · 衬线 · 杂志）：衬线标题 + 等宽数字 + 细分割线，报价如期刊专栏
- [x] 双态：每款提供「展开 · 侧边栏」与「收起 · 图标栏」两种形态
- [x] 统一语义配色：高峰 = 暖色（橙 / 琥珀 / 红），空闲 = 冷色（蓝 / 青 / 绿）
- [x] 公共结构：时段徽章、时间轴、价格表切换、价格表、页脚（共用 001 契约）
