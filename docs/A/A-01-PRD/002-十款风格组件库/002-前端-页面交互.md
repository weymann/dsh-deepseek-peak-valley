# 002-十款风格组件库 · 前端-页面交互（Web）

> 状态: 草稿 | 读者: Web 前端（其余不读）

## 0. 公共结构（全部风格共用）

每款展开态遵循 001-前端-页面交互 §2 的骨架：**头部（名称 + 时段徽章）→ 时间轴 → 价格表切换 → 价格表 → 页脚**；
收起态为**紧凑指示器 + 峰/闲 文字**，位于侧边栏左下角、设置图标（齿轮）上方。
时段切换、价格表展开/收起、可访问性均按 001 契约，本文件只记录每款视觉差异。

## 交互细节与可访问性

- 全款共用：时段切换（`data-set-period` / `aria-pressed` / `body[data-period]`）、价格表切换（`.w-toggle` / `aria-expanded` / `.is-collapsed`）、设置入口（齿轮「设置」）；
- 脉冲圆点 2.4s 循环脉冲、光标位移动画 0.3s（昼夜风格 0.35s 明暗过渡）；
- `prefers-reduced-motion: reduce` 时全部动画关闭；
- 图标均 `aria-hidden="true"`，时段信息同时以文字（高峰/空闲、峰/闲）传达，不依赖颜色。
