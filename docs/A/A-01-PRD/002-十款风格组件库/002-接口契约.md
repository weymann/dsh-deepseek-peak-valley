## 0. 接口形态说明

本项目为纯前端 DSH client widget，无后端 HTTP 接口（002-后端-数据服务 不填）。
本契约以「类型 / 数据结构」形式定义风格目录。

## 2. 风格目录类型（002 权威）

```ts
/** 风格编号：'01'…'10' */
export type StyleId = '01' | '02' | '03' | '04' | '05' | '06' | '07' | '08' | '09' | '10'

/** 单款风格规格 */
export interface StyleSpec {
  id: StyleId
  nameZh: string        // 中文名，如 '脉冲'
  nameEn: string        // 英文名，如 'Pulse'
  enLabel: string       // 设计稿英文标签，如 'DARK · NEON DOT · TECH'
  tags: string[]        // 风格标签，如 ['深色','发光','科技']
  description: string   // 风格描述
  stage: {
    expanded: string    // 展开 · 侧边栏 形态说明
    collapsed: string   // 收起 · 图标栏 形态说明
  }
  /** 语义强调色：高峰暖色 / 空闲冷色（全系列统一语义，色值随风格落地） */
  semantic: { peak: 'warm' /* 橙/琥珀/红 */; idle: 'cool' /* 蓝/青/绿 */ }
}

/** 风格目录：全部 10 款 */
export type StyleCatalog = Record<StyleId, StyleSpec>
```

## 4. 双态约定

- 每款风格消费 001 的 `DualState`（`expanded` / `collapsed`）与 `PeriodState`（`peak` / `idle`）；
- 展开 · 侧边栏：完整报价（头部 / 时间轴 / 价格表 / 页脚），结构按 001-前端-页面交互 §2；
- 收起 · 图标栏：紧凑指示器 + 峰/闲 文字，置于侧边栏左下角、设置图标上方；
- 时段切换时十款同步响应，不引入每款独立时段状态。

## 5. 语义配色（统一，逐款落地）

- 高峰 = 暖色（橙 / 琥珀 / 红），空闲 = 冷色（蓝 / 青 / 绿）；
- 每款以 `--peak` / `--idle` 语义变量表达，`body[data-period]` 决定当前强调色；
- 例外（09 昼夜）：用「白昼 / 夜空」整体明暗表达时段，语义仍遵循暖=高峰、冷=空闲。
